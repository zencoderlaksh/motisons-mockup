How to Deploy This Project on Netlify

This repository is pre-configured with pure client-side architecture and relative file links. No build commands, bundling, or node dependencies needed.

1

Login to Netlify

Visit app.netlify.com/drop in your browser. Netlify Drop accepts immediate static website folders.

Netlify Drop Ready
2

Drag & Drop Folder

Simply drag this entire folder (motisons-mockup) into the Netlify Drop area.

Zero Build Setup
3

Instant Live URL

Netlify will instantly generate your live HTTPS URL (e.g. motisons-mockup.netlify.app). Visitors start at / (index.html) and can seamlessly switch between all 4 mockups!

Live in 10 seconds
